# Vehicle artwork

Generated specifically for SendRack using the image-generation tool on 11 November
2026. Transparent miniature 3D illustrations: Nigerian Keke NAPEP, compact car,
helmeted dispatch courier, compact box truck. No third-party app branding or
photographs were copied. The provided app screenshot guided layout and category
selection, not image copying. Original generated PNGs remain in the workspace's
generated_images directory. Production assets are resized WebP derivatives in
web/assets/vehicle-{keke,car,dispatch,truck}.webp, served and packaged locally.
