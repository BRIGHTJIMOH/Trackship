# Communication cards

Owner console → Communication cards. Add a title/message, choose vendors, riders/drivers or both, and optionally select an in-app button. Dates accept ISO timestamps with timezone, for example `2026-11-24T09:00:00+01:00`; blank start means now and blank end means until turned off.

- **Save draft** does not change the currently published card.
- **Preview** shows the draft locally.
- **Publish card** publishes a new announcement identity. Online vendor/rider Home screens check within 30 seconds, on reconnect or on returning to Home.
- **Turn off** withdraws the published card on the next online check.
- Users may dismiss cards. A dismissal is remembered per published card/account/device. Republish deliberately to show changed content again.
- Cards do not appear on login, locked accounts, shipment forms or active delivery screens. No unsolicited push notification is generated by this feature.
- Publishing requires the owner session and CSRF protection. Regional managers and operator bearer tokens cannot publish. Only plain text and approved in-app destinations are accepted. Stale revisions are rejected.
- Existing APKs have bundled screen code. Install version 0.7.40-fcm or newer to display these cards; deploying the server alone cannot update older APK assets.
